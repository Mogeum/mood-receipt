# 기획 — mood-receipt

## 제품 한 줄 정의

개인 문화 경험을 영수증 형태로 기록하고 쌓아보는 노트 서비스

## 제품 목표

사용자가 영화, 전시, 책, 공연 등 문화 경험을 영수증 형태의 기록으로 남기고 오래 쌓아볼 수 있게 한다.

---

## MVP 기능 범위 (v1)

### 1. 구글 로그인
- Google OAuth 2.0
- 로그인 후 JWT 발급

### 2. 영수증 작성
영수증 = 하나의 문화 경험 게시글

| 필드     | 타입     | 설명                              |
| -------- | -------- | --------------------------------- |
| 카테고리 | enum     | 영화 / 전시 / 책 / 공연           |
| 제목     | string   | 콘텐츠 제목                       |
| 감상일   | date     | 관람·구매 날짜                    |
| 장소     | string   | 관람 장소 (선택)                  |
| 별점     | number   | 0.5 단위, 0~5점                   |
| 감상     | string   | 짧은 한 줄 감상                   |
| 이미지   | string   | 직접 업로드 or 외부 API 자동 채우기 |

이미지 전략:
- 영화/책: TMDB·네이버 책 API로 자동 검색 후 채우기
- 전시/공연: 직접 업로드
- 공통: 없으면 직접 업로드 fallback

### 3. 내 노트 페이지
- 로그인한 본인만 볼 수 있음
- 내 영수증 목록 시간순

### 4. 영수증 공개 링크
- `/receipt/:id` — 비로그인으로도 열람 가능
- 영수증 1개에 대한 링크만 공유
- 그 외 모든 기능은 로그인 필요

---

## 2차 기능 (v2 이후 — 지금은 고려하지 않음)

- 이미지 PNG 추출 공유 (카카오·인스타 공유용)
- 팔로우/팔로워 소셜 기능
- 전체 노트 공개 프로필
- 테이프 모양·색깔 커스터마이징 (영수증 작성 시 선택)

---

## 타겟 사용자

전시·미술관, 책·문학, 공연·음악, 영화·영상 등 문화 콘텐츠를 즐기며 감상 경험을 오래 기록하고 싶은 사용자.
자신의 취향과 문화생활을 다른 사람과 공유하고, 꾸준한 기록 습관을 만들고 싶은 사람.

---

## 차별점

단순 목록·카드 그리드가 아니라 찢어진 하단선, 점선 구분선 등 영수증 디자인을 기록의 기본 단위로 사용.
영화·전시·책·공연을 하나의 공통 형식(영수증)으로 자연스럽게 아우름.
